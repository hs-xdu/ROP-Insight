# MVP 验证记录

本页保留 MVP 历史验证。新增后台任务基础的记录见 [P2-A 验收记录](P2_A_VALIDATION.md)。

## 环境与范围

验证环境：Windows 64 位、Python 3.12、PyQt6 6.10.2 / Qt 6.10.2。使用临时生成的合成图片，未使用患者图像。本次交付为可从源码运行的 MVP，未制作安装包。

## 已执行验证

- 使用 pytest 和 pytest-qt 运行全部文档、加载服务和窗口测试。
- 验证 JPEG、JPG、PNG、中文路径、大小写扩展名、元信息及源文件不被修改。
- 验证无效格式、扩展名伪装、文件缺失、权限拒绝、损坏图片及像素超限。
- 验证初始状态、导入、重新选择、取消、失败保留旧图、清除和失败恢复。
- 验证横图与竖图自适应、窗口调整、按钮与滚轮缩放、缩放边界、鼠标拖动，以及 Ctrl+O 导入。
- 验证项目可编辑安装及 `pip check` 依赖一致性。
- 启动 GUI 进程，并检查真实 Qt 控件生成的初始界面与加载后截图，确认默认窗口和最小窗口布局可读。

复现命令见 [README](../README.md)。

## 待人工确认

桌面自动化工具因环境错误无法连接，以下真实桌面操作仍需人工检查，自动化测试与控件截图不能代替这些步骤：

- [ ] 按 README 启动应用，在系统文件选择框中实际选择 JPG、JPEG、PNG 文件。
- [ ] 检查鼠标滚轮缩放、放大后拖动的实际手感及显示缩放设置下的布局。
- [ ] 使用目标设备导出的典型大图检查加载等待时间，决定是否需要后台解码。

默认同步读取，限制为 4,000 万像素与 256 MB 解码分配；可在加载服务构造参数中调整。当前验证不包含 AI、诊断准确性或安装包分发。
