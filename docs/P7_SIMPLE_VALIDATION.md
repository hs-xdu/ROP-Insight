# 精简 P7-A / P7-B 使用与验收

已完成历史查询和只读恢复，待用户人工验收。P7-A提交b1a259c；P7-B提交主题`feat: restore saved analysis and original reports in simplified history`，短哈希见交付回复。无数据库迁移、依赖安装、模型或P4/P5格式修改。

## 打开和简单验收

```powershell
cd "E:\8 大论文\ROP_System"
.\run-platform.ps1
```

1. 点击左侧“历史分析记录”，选之前P6保存时的资料库文件夹（含rop_insight.db）。若当前已选库则直接载入。
2. 输入病例编号搜索，清空应显示全部；不存在的编号显示“无匹配记录”，空库显示“暂无保存记录”。
3. 选中一条记录，点“查看分析结果”。确认原图、Mask/叠加、A6概率、量化、连续评分及区间、SVM结果可读；左侧结果可滚动，图像可缩放和平移。
4. 点“查看已有报告”，切换“原报告正文/原PDF”；点“导出已有PDF”使用新文件名另存。没有报告时明确提示未生成。
5. 点击“返回当前分析”，当前工作台图像、运行及病例选择应保持原样。重启后再选同库也能查询。

## 实现范围

新增services/record_history.py、ui/record_history.py、ui/saved_report.py及对应测试；main_window只增加历史入口与安全关闭协调，local_records增加只读打开/可取消校验参数，默认P6保存行为保持不变。

P7-A读取cases/analysis_records并核对管理清单及分析JSON，显示编号、眼别、日期、分析时间、A6预测与终态。坏记录保留异常提示，缺失A6不显示Normal。编号搜索不分大小写，清空恢复。每次最多读取最近保存的1000条匹配记录，再按分析时间倒序展示，超过上限提示缩小搜索范围。

P7-B以校验后的原图字节、二值Mask及JSON恢复展示对象，不创建AnalysisController或执行适配器，不载入权重，不写历史结果。模块失败/跳过/取消保留原因；缺值不补0。原始JSON、模型版本、哈希与来源可在详情标签查阅。解析校验图像身份、尺寸、Mask引用/二值及对齐、分类标签/概率和来源快照；未知格式或坏文件拒绝恢复。

历史窗口拥有独立ImageView和ResultPanel，切换记录立即清空旧视图，晚到的其他记录回调丢弃；当前工作台运行对象不变。选择改变或搜索时不沿用旧报告。

报告读取原TXT及原PDF，不调用report_builder，不重新生成临床文字或PDF。报告缺失/损坏不妨碍已有完整分析的查看；原图缺失时仍允许单独打开校验合格的原报告。另存PDF校验后原样复制且不覆盖已有目标。PDF从固定字节缓冲读取，关闭时显式解绑、关闭文档及缓冲，防止原生资源回收顺序问题。

所有查询/哈希/解码/复制通过现有QThread工作器，取消在文件与读取块边界生效，正常关闭等待安全结束。只读历史打开不隐式建库或重建索引。完整性哈希不是数字签名，不实施对比、归档、删除、多图聚合、备份恢复或医疗审核。
