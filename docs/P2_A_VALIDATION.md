## 3. 用户操作验收

正常启动仍使用 `run.ps1`，导入图片后显示“分析模块未配置”，这是尚未接入真实模型的预期行为。

要查看后台分析基础，在项目目录运行专用工程验收窗口：

```powershell
.\.venv\Scripts\python.exe tests/manual_p2_a.py
```

窗口标题标识“工程验收”，仅运行约五秒的可取消任务，不做分割或分类，不产生诊断数字。使用任意合成测试图片即可。

- [ ] 导入图像并开始分析，显示“分析中”，开始禁用，取消启用。
- [ ] 分析中仍能缩放和拖动；等待任务结束后显示“分析完成”。
- [ ] 再次开始并取消，显示“分析已取消”后可以重新开始。
- [ ] 分析中换图或清图，旧任务退出后不能出现旧图的完成结果。
- [ ] 分析中关闭窗口，安全退出后无运行中 QThread 销毁警告。

以上实际操作确认后再勾选。自动化线程测试和 Qt 截图不替代人工操作验收。

## 4. 二次选图侧栏变形修复与复验

用户反馈第二次选择图片后按钮变宽、右侧被裁切。使用与反馈相似的中文、下划线和 UUID 长文件名复现：布局的双轴 SetMinimumSize 约束将侧栏最小宽度从 250 推高到 508 像素，而外层滚动区域仍为固定宽度。

修复为水平不扩展、纵向保留最小尺寸的独立约束；文件名称和分析状态标签忽略水平尺寸提示，文本不再决定面板宽度。完整文件路径仍可悬停查看。小窗口继续通过纵向滚动访问全部信息，不使用横向裁切按钮来容纳长内容。

新增回归先在旧代码下失败，再在修复后通过，覆盖默认及 800×560 窗口下短名称、二次长名称、150 字符连续名称、再次短名称和清除；逐次检查侧栏固定宽度、按钮几何尺寸、横向滚动范围、文件信息和 tooltip。另测长模块错误提示不撑宽侧栏。
