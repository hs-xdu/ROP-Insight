## 本轮真实执行

使用 `scripts/validate_system.py`，原文件只读，证据在 Git 忽略的 `.runtime/p4-validation/`。

- 完整参考流程：五模块成功，十项指标绝对差异全部为0，导出 JSON、两张 Mask 和叠加图；缩放/拖动后二次叠加 PNG 字节一致，清图后导出禁用且旧评分清除。截图经视觉检查，结果可侧栏滚动查看。
- 部分失败流程：仅在测试配置中设置 A6 缺权重，A6 正确失败，其余四模块成功；十项指标差异仍为0，部分成果导出成功，A6 无残留预测。不改动正式配置。
- 完整流程约29.09秒，Vessel 15.06、A6 3.76、量化7.00、SVM 3.17秒；部分失败约25.11秒。包含环境启动等开销，仅为单次观察。
- Qt 50ms心跳完整流程最大间隔约0.203秒；GUI峰值工作集约75.2 MiB，不含算法子进程。GPU每秒采样整卡已用显存最大9809 MiB，包含其他进程，不是该模型精确峰值或最小显存需求。
- 4000×3000合成图在800×560窗口完成加载、缩放、适应和原尺寸导出；加载约0.047秒，导出约0.406秒，GUI峰值工作集约393.4 MiB。仅测I/O/显示/导出，不含模型。
- 未约定性能SLA，不把这些观察作为跨设备性能合格线。CPU-only完整模型流程和无开发环境安装包未验证。

本机自检通过权重/源码哈希、主要包实际导入和CUDA可用性。A6环境有PyTorch元数据与实际导入版本差异，见 [环境说明](ENVIRONMENT_LOCK.md)，未修改研究环境。

## 自审与修正

结果、配置和图像快照分离；QImage 使用 copy，其他结果深拷贝。文件名来自固定图层名，模块ID不用于拼接文件路径。原子发布、同名拒绝、未知字段白名单、绝对路径移除、失败清理及重试均有测试。原数组0/1与导出PNG 0/255分别保留。

后台导出安全关闭，关闭等待期间禁止新分析；取消、迟到结果、依赖跳过沿用既有回归。补测清图时仍导出选定快照、失败后可重试及线程退出。未发现未处理的阻断性实现问题。

本轮真实证据在开发工作区生成，code_dirty=true，如实保留运行时上一个commit；不可改写为最终提交后的干净运行。提交后可按 [运行手册](RUNBOOK.md) 复验。自动 Ridge、新设备交互、全数据集再评估及临床有效性仍未完成，不在论文中描述为全部通过。
