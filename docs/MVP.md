# ROP-Insight MVP 设计文档

## 1. 项目目标

开发一个面向 ROP 眼底图像的本地可视化软件，为后续智能分期、病理结构分析和量化分析功能提供基础软件框架。

第一阶段仅实现眼底图像导入、预览和基础管理，不涉及 AI 模型推理。

## 2. 核心功能

### 2.1 图像导入

- 支持 JPG、JPEG、PNG 格式。
- 支持单张图像导入。
- 支持重新选择和清除图像。

### 2.2 图像展示

- 显示眼底原始图像。
- 支持图像自适应窗口缩放。
- 支持图像放大、缩小及移动。
- 显示图像文件名、分辨率和格式。

### 2.3 基础交互

- 提供清晰的图像导入与展示界面。
- 显示当前图像加载状态。
- 对文件格式错误、读取失败等情况提供提示。

## 3. 系统界面

采用单窗口布局，划分为三个区域：

- **顶部：** 软件名称及基础操作。
- **左侧：** 图像导入、文件信息及图像操作。
- **中间：** 眼底图像预览区域。

底部显示软件运行状态。

## 4. 技术方案

- 开发语言：Python 3.12。
- GUI 框架：PyQt6。
- 图像处理：Pillow、OpenCV（按需使用）。
- 运行方式：Windows 本地运行。

采用模块化设计，分离界面、图像加载和图像展示逻辑，为后续算法模块集成预留接口。

## 5. 第一阶段功能边界

暂不实现：

- ROP 分类模型及智能分期。
- Ridge、Vessel 等图像分割模型。
- 病灶及血管量化分析。
- 辅助诊断结果生成。
- 病例数据库与患者管理。
- 批量图像处理。
- 云端部署及用户管理。

## 6. 验收标准

1. 能够正常启动软件。
2. 能够导入并显示 JPG、JPEG、PNG 图像。
3. 图像能够自适应窗口显示。
4. 支持放大、缩小及移动图像。
5. 能够正确显示图像基本信息。
6. 能够处理无效文件和图像读取异常。
7. 界面布局清晰，模块结构便于后续扩展。
