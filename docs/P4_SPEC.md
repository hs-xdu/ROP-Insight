# P4-A / P4-B 实施约定

用户本轮授权连续实施两个阶段并自行审查。沿用原算法、原环境、手动 Ridge 与已确认的 11 项 SVM 输入，不增加训练或结果融合。

P4-A：新增结束任务的统一导出快照、侧栏导出入口；导出 result.json、原图尺寸二值 Mask 和固定配色叠加 PNG。保存文件/像素/权重/代码哈希、软件版本、参数、依赖、时间、状态与工件文件哈希；不导出原始文件名、完整路径、原图副本或原实验中间工件。叠加图含原图视觉信息，应由用户主动选择导出位置。完整目录先暂存后原子发布，不覆盖已有成果，失败清理本次暂存目录。

P4-B：完善启动、自检、环境约束、系统验证及论文材料索引。自动化验证全流程、部分失败、取消、换图、异常导出和视图变换独立性；在现有 Windows/GPU/参考样本上做真实联调与资源观察。源代码交付，不承诺未经验证的安装包或设备性能。按 V2 九项记录证据；自动 Ridge、用户交互手感与临床有效性仍分别记录限制，不提前标记 V1.0 全部验收。

实施顺序：快照与导出服务 → 界面入口 → 导出与生命周期测试 → 运行自检及参考验证脚本 → 真实运行 → 自审修正 → 全量测试和文档 → Git commit。用户授权取代此前“每次仅实施一个子阶段”的规划限制。
