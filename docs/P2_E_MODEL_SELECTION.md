# P2-E 分类模型候选与选择

## 1. 本次范围

用户已确认 P2-D 验收完成，要求搜索 `E:\ROP_Experiments` 中符合条件的模型并由用户选择最终分类模型。本次只完成候选筛选，不提前绑定权重、不重新训练、不开始分类适配器实现。

筛选条件：现有四分类定义、可定位的 best.pt、配套模型代码和已保存的正式测试指标。已核查下面七组候选的两个医院版本权重文件均存在；尚未逐个重新加载、推理或验证这些权重与平台输出的一致性。

详细权重路径、文件大小、指标源文件及源报告 SHA-256 保存在 [候选工件记录](CLASSIFIER_CANDIDATES.json)。这些是医院分别训练的不同权重，不是一个模型同时在两个医院外部验证的成绩。

## 2. 主要候选

数值均为已有记录中的测试集 Accuracy / Macro-F1（百分比），seed=42；未以测试成绩重新选择 checkpoint。

| 候选 | 简要结构及输入 | 深圳 Acc / F1 | 西京 Acc / F1 | 接入考虑 |
| --- | --- | --- | --- | --- |
| A0 | VGG16-BN 双分支，分别输入 RGB+Ridge、RGB+Vessel，拼接全局特征 | 82.14 / 79.90 | 81.25 / 74.69 | 结构直接；在此 A 系列候选的西京记录中较突出，但仍依赖 Ridge |
| A2 | A0 基础上增加 Ridge 引导的局部交叉注意力，Q 来自 Ridge，K/V 来自 Vessel | 88.39 / 85.77 | 71.25 / 62.62 | 适合突出结构先验与交叉注意力研究；西京这组权重的效果低于 A0，不能只看深圳 |
| A6 | 保留双分支与独立 RGB 编码器，Q=Ridge、K=Vessel、V=血管引导的 RGB 特征 | 87.50 / 84.98 | 73.75 / 69.28 | 兼顾结构与 RGB 内容，模型复杂度和部署代码更多 |
| A7 | 保留双分支与 RGB 编码器，Q=Ridge、K/V=全网格 RGB 特征 | 87.50 / 83.39 | 77.50 / 71.09 | RGB 内容扩展方案；虽 K/V 不按血管筛选，仍依赖 Ridge 和 Vessel |
| M2 | 纯 RGB、共享 ResNet50，224/168/112 内容尺度等权融合 | 86.61 / 83.30 | 67.50 / 58.39 | 不需要任何 Mask，可在继续暂缓 C 时先接通分类；需保留原缩放与黑边画布规则 |
| M3 | 与 M2 相同尺度，改用可学习的特征门控融合 | 81.25 / 74.89 | 67.50 / 60.54 | 同样不依赖 Mask，但并非在所有数据上优于简单等权融合 |
| B2 | 双 ResNet50，使用 Ridge 区域加权汇聚 Vessel 分支局部特征（lesion_pool） | 87.82 / 87.81 | 68.75 / 64.79 | 病灶条件聚合解释较直接；需要 Ridge，且深圳测试口径不同 |

深圳：A 系列为 shenzhen_v2 的 112 张测试图；M2/M3 为原始 RGB 金字塔方案的 112 张测试图；B2 为另一份 156 张测试图。即使样本数相同，也不能仅凭数量认定成员及预处理相同，不将这些结果混排成统一榜单。西京各组记录均为 80 张，但分别训练，选择前仍需核对数据版本与输入流程。

部分原实验明确保留了历史划分、重复图或患者独立性限制；单种子结果和内部测试不能作为跨院泛化结论。这里的筛选仅评估工程可接入性和既有研究证据，不重新宣称临床性能。

另外发现纯 RGB 注意力 R0—R4、YOLO26m-cls 和 ResNet50 单/双分支实验；它们也有可定位的工件。上表优先列出与当前技术方案和第四章结构先验路线相关的候选，并保留无 Ridge 依赖的纯 RGB 方案，未排除用户另选其他模型。

## 4. 选择建议与下一步

- 希望先完成独立分类闭环、继续暂缓 Ridge：优先考虑 M2；其分类不使用已经接入的 Vessel，血管结果可以独立展示。
- 希望最终平台体现第四章结构先验和交叉注意力：重点比较 A2、A6、A7，并补齐 C 或明确提供的 Ridge 输入方案；不能用全零/合成 Mask 冒充实际病灶结果。A7 并不是纯 RGB 模型。
- 希望使用结构较直接的病理双分支基线：考虑 A0；希望展示病灶条件血管特征汇聚：考虑 B2，但需接受其独立数据口径。

请用户选择模型编号及权重版本（深圳或西京，亦可明确保留两套并人工切换）。没有证据支持自动判断图片来自哪个医院，不设计自动路由，也不默认融合不同模型概率。

选定后再固定 checkpoint 哈希、标签顺序、原预处理、Mask 编码和运行环境；沿用独立进程模式接入 E，并用原脚本参考概率做一致性验证。所有权重、病例图和逐图预测留在原实验目录，不加入本仓库。
