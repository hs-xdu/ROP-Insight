# ROP-Insight v0.2.0（研究预发布）

发布日期：2026-11-26。此版本是源码研究预发布，不提供Windows安装包，也不宣告原V1.0全部验收完成。

## 功能

- 保留已有图像预览/缩放/平移、手动Ridge、VascX Vessel、A6深圳四分类、11项量化/连续评分和95%后验区间、冻结RBF-SVM。
- P5固定模板报告：预览、PDF/文字/JSON导出，三项共有指标文字说明。
- 精简P6：两表SQLite、匿名病例创建/选择、主动保存原图与分析、重复保存去重、可补充报告。
- 精简P7：病例编号搜索、历史图像/图层/结果只读恢复、原报告正文/PDF查看及PDF原样另存；不重新推理、不覆盖当前分析。

## 整理

旧MVP/P2-A验收、旧平台借鉴盘点和回退记录集中到docs/archive；保留论文证据。删除已被自动化测试替代的manual_p2_a.py，保留被测试引用的manual_p2_b.py和模型验证工具。README更新为当前工作台指南。源码与新运行/报告生成元数据统一标识0.2.0，不改旧记录或旧报告版本。

## 验证与边界

完整自动化测试210项通过（功能基线206项及发布整理新增4项）。新版本元数据、历史文档链接和私有文件排除均有检查。数值算法及权重未修改，未重训模型，也未重新将工程对照解释为模型性能结论。

源码不包含权重、专用推理环境、本地配置、原图、病例数据库或导出报告。现有本机使用run-platform.ps1；新机器须按docs/RUNBOOK.md另行配置环境和权重。仅查看图像可用run.ps1。自动Ridge暂缓，无多图聚合、对比、归档删除、云端或身份管理。

历史版本由Git提交/标签追踪。GitHub为本标签提供源码ZIP/TAR下载；这不等于已打包成可双击的Windows程序。
