# P2-B 图层与结果面板实施说明

用户确认 P2-A 验收完成并要求继续实现。本段依据 [技术方案](TECHNICAL_PLAN.md) 和 [路线图](IMPLEMENTATION_ROADMAP.md) 实施图层、切换、透明度及结果面板，范围不包含真实模型与算法；P2-A 验收确认不等于真实模型效果验证。

## 1. 实施计划与接口

1. 在 AnalysisOutput 上兼容扩展 MaskData 与 ClassificationData，保留已有 JSON values；后台输出校验通过后才回传。
2. MaskData 使用原图坐标的 width、height、不可变 0/1 bytes；不隐式缩放或阈值化错误尺寸的数据。原生模型空间及逆映射留给真实适配器实现。
3. ClassificationData 显式采用 Normal、Stage 1、Stage 2、Stage 3 顺序的四项概率，要求有限、范围 0~1、和为 1；不在展示层计算 softmax。并列最大值按既定顺序显示。
4. ImageView 使用原图、黑白 Mask 和彩色透明叠加项，所有项共享同一场景坐标和视图变换。切换可见性不重新加载图片，不重置缩放或中心。
5. 主窗口接收具有匹配 image_id/run_id 的结果；新运行、换图或清除时重置旧图层与概率。失败、跳过、取消模块不产生新的展示输出，已成功模块继续保留。
6. 固定宽度侧栏中增加结果面板：显示模式、Ridge/Vessel 开关、透明度、模块状态及四类概率。没有可信输出时显示“未提供”并禁用相关操作。

## 2. 验收标准

- B01：无结果时概率不伪装成预测、Mask 模式不可选择；原图交互和侧栏宽度回归通过。
- B02：错误类型、字节长度、非二值编码、错误尺寸与非法概率被拒绝，原始数据不变。
- B03：已知几何图形的 Mask 与原图同尺寸同坐标，背景透明且前景颜色独立。
- B04：原图、两个单独 Mask 和叠加模式切换正确；透明度与开关生效，缩放和平移不变。
- B05：成功结果显示预测类别与对应概率；显示舍入不修改结果数据。
- B06：真实后台线程到面板的链路通过；换图、清除与迟到结果隔离通过。
- B07：全量回归、依赖及默认/最小窗口渲染检查通过；用户使用合成验收脚本实际确认交互。

## 3. 验收操作与状态

P2-B 代码已实现，自动化与 Qt 渲染结果随本次交付记录；用户实际操作待确认，不进入 P2-C。

本次 Windows / Python 3.12 / PyQt6 6.10.2 环境下全量测试为 74 passed，pip check 通过。新增测试覆盖错误 Mask/概率、原图对齐、透明背景与前景颜色、变换保留、后台到面板链路、旧结果清除、合成 Mask 的奇数宽度行对齐；原有长文件名、取消和线程退出测试保持通过。已检查合成任务完成后的默认窗口叠加图渲染；小窗口渲染确认侧栏宽度及按钮宽度不变。上述自动化与控件渲染不代替用户实际操作验收。

```powershell
.\.venv\Scripts\python.exe tests/manual_p2_b.py
```

窗口标题明确标注合成数据。导入测试图片、开始分析，约一秒后出现合成环形 Ridge 与线形 Vessel。左侧向下滚动至“结果与图层”，逐项检查原图/Mask/叠加、颜色、透明度与开关；缩放拖动后切换结果应保持观察位置。再换图、清除、重复分析，确认旧结果移除。测试概率固定为 10%、20%、60%、10%，仅用于展示契约验收，不代表模型输出。

正常应用不会生成上述合成结果。后续用户要求暂缓 P2-C、优先 P2-D，已通过原实验工件增加真实 Vessel 适配器，运行方式见 [P2-D 说明](P2_D_SPEC.md)；本页保留 B 阶段合成验收流程。
