# P5 结构化辅助分析报告：实现、使用与验证

## 1. 使用

执行 `run-platform.ps1`，导入原图和对应 Ridge，运行分析。任务结束后点击左侧“预览辅助分析报告”。窗口包含简要/详细两页签；详细页签即PDF正文内容。点击“导出PDF报告”，选择已有文件夹，后台生成独立的 `rop-report-随机ID` 目录。

输出包括：

- `report.pdf`：A4中文详细报告，页眉、页码、特征表和说明章节。
- `report.json`：不可变报告快照的完整数值与来源；保存原浮点精度。
- `report_summary.txt`、`report_detail.txt`：固定模板简要/详细文字。
- `report.html`：同源详细正文，供查看/比对，不含脚本或远程资源。
- `report_manifest.json`：报告ID、图像/运行ID、输入哈希、来源快照哈希、页数及各输出文件SHA-256。

失败、取消、部分成功的终态也能生成明确标注不完整的报告；无图、跨图或仍在运行的任务不能生成。报告不需要病例信息；P6/P7未在本轮实现。

## 2. 报告内容与数据规则

当前固定模板 `p5-factual-3`（P6新增匿名病例段；三项指标文字规则保持不变，上一版p5-factual-2）（初版为p5-factual-1）借鉴用户提供的旧报告简化/详细层次和说明结构，不执行旧报告提取流水线，不复制22项经验分档、plus/分区倾向或综合印象。没有新增模型推理、阈值或大语言模型判断。

本次增量仅为VD、FD、最大局部密度变化增加“血管量化文字摘要”和详细报告中的“重合指标分项说明”，包含指标含义、本次数值/网格、状态及核对提示。固定规则版本common-three-factual-1随report.json保存；未启用分档，grade/reference_interval为null。数值为0仍作为有效值；缺失或非有限时明确不作对应形态描述。预览、TXT、HTML与PDF内容同源，原11项特征及模型输出不变。

报告包含 A6预测及四类概率、Ridge/Vessel来源/状态/原图尺寸、固定11项特征、连续评分及95%后验区间、独立SVM、模块状态、限制和版本。11项按冻结SVM顺序：FD、VD、最大局部密度变化、T1、T3、B3、Ridge面积比例/实心度/外环血管密度/最大径向位置、S_median。T1来自原生 feature_values，单位无量纲、1024网格；其余单位和网格取自原量化输出。

不可用/非有限/未通过质量规则的数据使用null及原因，不写成0、正常、中等。失败模块的旧输出不会进入报告；多个同类来源冲突时标记不可用。A6标签顺序、有限性、概率范围和总和需有效；SVM无校准时只给类别。后验区间需有限、有序、宽度一致且中位数对应S_median。

JSON保存原精度，文字统一使用最多12位有效数字，A6另显示两位小数百分比，仅供阅读。简要/详细/PDF由同一报告数据和章节函数生成，不进行模型融合或临床推断。

## 3. 接口与实现

`report_builder.build_report(ExportSnapshot)` 从结束任务生成报告，`report_from_result(result)` 也可读取P4 schema_version=1结构。后者只读取给定JSON，不访问其文件引用，不提供P7历史列表或自动重开入口。

`ReportDocument` 以冻结JSON字符串持有数据，`.data` 返回独立副本；`report_schema_version=1`。来源快照只包含当前协议的图像/运行/模块字段，去除本地路径，使用标准顺序的有限值JSON计算SHA-256。同一分析从实时快照和P4 JSON生成时来源哈希一致。

来源分析的版本/commit/dirty保持原记录；报告生成器另记录当前软件、commit/dirty、PyQt及Qt版本，并保存模板版本。两者不混用。Git或输入哈希无法获得时明确未记录，不虚构最终干净版本。

预览采用QTextBrowser，禁止打开链接；动态内容进行HTML转义。PDF用QPdfWriter/QTextLayout/QPainter逐行排版，字体为Microsoft YaHei及系统后备字体，无截图缩放。短评分/SVM段保持整段分页，超长原因按行跨页，表头重复；避免富文本跨页裁切造成隐藏文字重复或尾段截断。没有新增pip运行依赖。

报告PDF在现有QObject/QThread后台导出框架中生成。父目录下独占暂存目录，所有文件写入并验证后原子发布；不覆盖历史成果。写入失败只清理本次暂存目录并允许重试。主窗口关闭时等待导出结束；换图/清除会关闭旧预览，已启动导出使用其固定快照，不混入新图。

## 5. 复验与限制

运行既有参考验证命令时添加 `--report`：

```powershell
.\.venv\Scripts\python.exe scripts\validate_system.py --config configs\p3b.local.json --image "E:\reference\image.png" --ridge "E:\reference\ridge.png" --reference "E:\reference\expected_features.json" --output ".runtime\p5-check" --report
```

本机Windows中文字体及已授权参考样本通过；其他设备应检查字体、PDF版式与原环境。报告为研究辅助输出，不是医生确认的诊断，不提供治疗建议。自动Ridge仍暂缓；P6病例信息、P7历史列表、正式医疗审签及完整V1.0验收不由本轮替代。用户可进一步人工检查实际交互和新样本报告。
